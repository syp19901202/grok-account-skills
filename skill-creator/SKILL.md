# 技能创建器

用来创建新技能，并迭代改进它们。

创建技能的高层流程是：

- 先决定这个技能要做什么，以及大致怎么做
- 写一版技能草稿
- 准备测试用例 / 评测标准
- 按反馈评测并迭代
